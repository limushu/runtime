讲解点：为什么等待不会卡住系统？

Workflow 已是 Pending。资源队列却已就绪，所以 Driver 可以处理另一个分支。

展开 Acquire → Permit → 再次 poll
  1. Workflow 发送 Acquire，当前 Future 等待 oneshot。
  2. 同一个 Driver 读取资源事件，由 LockTable 决定放行。
  3. Permit 通过 Waker 让 Future 可再次轮询，尚未执行业务。
  4. Driver 再次 poll，Workflow 才能获得许可并发出 Activity。
