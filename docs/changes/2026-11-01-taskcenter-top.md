# TaskCenter TOP：运维终端重做

本页记录四页签方案，现已被[按池分层的界面](2026-11-01-pool-workflow-view.md)替代。
当前键位、步骤计数与完成语义以新说明为准。

## 目标与验收

第一版逐级文本列表不足以承担运维观察。此版本参考 [SPDK 官方 spdk_top](https://spdk.io/doc/spdk_top.html)
的表格页签、键盘导航与详情弹窗模式，重做展示与交互；不复制其代码、不引入 SPDK 依赖。
这不是 SPDK 性能采集器，也不声称已有 RPC 或 CPU / poller 指标。

- 一屏看到全局池数、非终态任务、等待、暂停、异常、历史任务数。
- 四个固定页签：Pools、Workflows、Activities、Events；有列标题、选中行、分页、排序和列选择。
- 保留池 / 工作流 / execution / 步骤范围；回退恢复原来的选择与搜索，不跳到新到达的行。
- 宽度至少 124 列时显示右侧检查器；窄屏保留表格和两行选择摘要，d 打开完整详情。
- 80×24 显示 9 行数据；最低 64×20，过小时提示调整窗口而不损坏布局。
- 任务默认按异常 / 等待 / 暂停等关注优先级排序；历史查询与审计原文保持完整。
- 详情先展示状态、步骤、进度、对象、阻塞者、准入说明、控制请求与执行批次；JSON 是 r 键的次级入口。
- 冻结建立一致的只读数据快照，后台继续读日志；解冻追上最新数据，不发送业务暂停命令。
- 刷新只更新有变化的终端行；不周期性清空整屏。正常退出、Ctrl+C、SIGTERM 恢复终端模式和光标。
- 实际事件缺少开始或结束时间时，EXEC TIME 显示 `-`，不将等待时间或进程存活时间伪造成执行耗时。

## 运行与操作

Node.js 22+，无需 npm install。使用已存在的审计文件，或按[持久化观测说明](2026-11-01-persistent-observation.md)启动主备交接示例：

```powershell
node tools/task-center-tui/index.mjs D:/Temp/实际文件.audit.jsonl
node tools/task-center-tui/index.mjs D:/Temp/实际文件.audit.jsonl --tab workflows
node tools/task-center-tui/index.mjs D:/Temp/实际文件.audit.jsonl --once --width 150 --height 40
```

建议终端 140×36 或更大；`--width / --height` 用于可复现快照，交互模式通常使用真实终端尺寸。

| 键位 | 操作 |
| --- | --- |
| 1–4 / Tab / Shift+Tab | 切换页签 |
| ↑↓ / j k、PgUp PgDn、Home End | 选择、翻页、首尾 |
| Enter、Esc / b | 下钻、关闭弹窗 / 回退 |
| d / r | 可读详情 / 原始审计记录；详情中 r 切换 |
| p / e | 选择池 / 选择工作流执行批次（保留旧主、新主记录） |
| f | Workflows：全部 / 当前 / 历史 / 异常 |
| / | 搜索当前表；Esc 撤销当前编辑 |
| s / c | 排序 / 列显隐；必选标识列不可隐藏 |
| a | 清除范围、筛选、搜索 |
| Space | 冻结 / 解冻数据视图；顶部显示积累的事件数 |
| h / ? | 键盘帮助 |
| q / Ctrl+C | 退出 |

首屏统计是**全局日志范围**，表格由当前范围与筛选决定。全部时间使用 UTC。
CURRENT 是最近报告的非终态，不表示宿主仍在线。READ OK 只表示文件读取成功，不能替代健康检查。
表宽不足时按优先级隐藏后面的列；c 可以隐藏靠前的可选列，d 总能看到完整字段。
小终端的表格截断以 `~` 标记；详情会换行并可滚动。终端控制字符会清理，避免日志驱动终端命令。

## 实现边界

- `reader.mjs`：只读 JSONL 适配器，增量 UTF-8 解码、完整帧校验、每轮读取预算、文件替换/截断保护。
- `model.mjs`：审计投影，保留历史、执行批次及上下文；不推测没有记录的业务结果。
- `presentation.mjs`：状态、时间、进度和可读详情转换。
- `app.mjs`：范围、表格查询、选择、排序、弹窗、导航及冻结状态；不访问文件或业务控制接口。
- `screen.mjs`：可测试字符帧、颜色与自适应布局；处理中文宽字符、组合字符与弹窗覆盖。
- `index.mjs`：组装输入、只读数据源和终端，按变化行刷新。

本次没有修改 Workflow / Activity 执行逻辑、审计格式、主备机制或 Rust 持久化接口。
文件后端、内存索引与只读客户端的既有限制仍然适用：没有跨机器 RPC、无限历史容量、主机心跳或业务控制命令。
冻结会复制当前投影，因此额外使用与当前记录规模相关的内存；用于观察，不是大规模归档检索方案。
